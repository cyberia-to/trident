# Joy source bridge for the original whole proofs

The read-only comparison ran `python3 -B -W error capture.py` against fixed Git
objects and existing installation/package metadata. Its [original review](objects/e5ebdecdab93311790884a9dfd69ddc2ecdf7f8e5fdc4ffd246f503cbaa20e99)
and raw Git commands are retained without byte changes.

Joy `6e0ec4d8440e2521df08f442d64f54e667044716` and its merge `11b7bad201cbfc03955290b5479fa6684f8e2b82`
have the same tree. Compared with packaged Joy `dd61df9128f6da1f97d4698f45f154f05312fe51`,
the sole production change is `COMPACT_TIME_MS` from 7,200,000 to 14,400,000 ms.
All nine non-Joy installation dependency pins match the final package, including
the exact Zheng semantic relation and Nox evaluator revisions. JOYSC001
transport, capture, context, verifier pipeline/session, JOB1/result handling and
Cargo manifests/lock are unchanged. Joy `15202f42240ba923398908ee0db62d32f1d655f8`
changes only README and CHANGELOG after that package source.

The change admits explicitly selected compacting deadlines above two hours
through four hours. Each process selects its own host deadline; certificate
context, the 30-second default, ordinary five-minute ceiling and logical work,
storage and proof limits remain unchanged. The separate retained bounded helper
trial observed identical certificate bytes across three selected producer clocks
and nine fresh verifier pairings. Its exact scope and commands remain in the
original trial receipts.

The original whole-proof Joy binary is 5,635,776 bytes, SHA256
`8f42591ece35f192ff6f2328a8360fe0f0959f48a173248b211cd0d8f4d984f9`.
The final macOS ARM package records Joy SHA256
`7b1aee370f6826db73f089054f261a3ef874ad54d2e259fbd26f7d8164ab6071`,
with source provenance `9334dead92b990a12acf16a2565aeb762a07311dfc2c3d6cb896c0490dc5926e`.
These are distinct binaries. Original full-proof results stay attached to the
original binary and selected profile. This source bridge supplies no fresh
full-certificate execution by the packaged binary and no SH8 acceptance verdict.

`retained-files.json` maps exact selected originals to deduplicated SHA256
objects. `references.json` identifies the two previously retained source maps;
their bodies are omitted here. No proof, binary, full-host process snapshot or
signed transport URL is copied. Original absolute paths are provenance only.

Run `python3 -B -W error verify-retained.py --originals` where original paths are
available, or omit `--originals` to check the archive alone. The verifier is the
unchanged `7084b3e31fff02d78533e48998ac2994afc1cbd2744a6586fe9335315ceae446`
implementation used by the sibling `integration-pr119` archive. Directory-local
`* -text` preserves every retained and generated byte during Git checkout.
