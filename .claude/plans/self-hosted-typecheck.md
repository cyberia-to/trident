# Historical RAM typechecker prototype
Superseded 2026-09-23 by [self-hosting on soft3](../../reference/self-hosting.md) and its [progress ledger](../../audit/self-hosting-progress.md). The original full plan is retained in git at `39ce297:.claude/plans/self-hosted-typecheck.md`.
The old proposal used RAM tables, integer type tags, a type pool, hashed names, two-pass signature/body checking, explicit scope stacks and bounded iterative graph traversal. It targeted the legacy lexer/parser/typecheck pipeline plus separate Triton benchmark proofs. Its line estimates and completion language did not establish native nox compilation, semantic preservation or a self-build.
Current ownership: `.tri` source compiler under `compiler/nox/` and `lib/std/compiler/nox/`, native Seq/Bytes data, JOB1/RES1, ART1 execution through Joy. Implement the next executable slice from the ledger; retain honest proof and resource boundaries. C1(S)→C2 and C2(S)→C3 remain the self-hosting acceptance.
