# SH3 native compiler literal-range loops
Next after scalars, feature PR into release/0.4. Contract first: `for name in A..B { body }`, decimal literal bounds, immutable U32 index; no dynamic/outer-index bounds or bounded annotations in this first slice. Actual compiler/native collections use literal loops. No break/continue language addition.

Bounds must scan raw source bytes rather than Goldilocks-normalized Token.value. Admit start<=U32_MAX and end<=2^32; reject larger values even when empty, a deliberately narrower domain than seed empty-loop elision. Decimal expressions elsewhere retain Field normalization. Leading zeros must not change values. Wrong types/returns in empty bodies still check.

Parser: for/in/range tokens; own bounded loop records, child-block IDs and two stable frame slots (visible index U32, hidden remaining Field). Preserve surrounding binding visibility, synthetic-if owner and return state on close; index/body locals stay scoped. Body tail is discarded. Literal nonempty ranges with end<=U32_MAX may satisfy return coverage only through explicit-return body, matching seed; end=2^32 still needs a fallback. Returning loops do not make that fallback syntactically unreachable.

Integration owners: loop_records/loop_parse modules plus body_state/body_store; conditional Frame.phase=2 owns a loop record while close restores the parent scope. Add code_plan over function_plan, reserving all function entries before loop entries and storing per-function loop bases. block_gen emits inline initialization/dispatch; loop_gen builds one iteration formula from the already emitted child block. control_gen returns function output and loop formulas; function_gen installs both and checks total table depth. Keep the old body-record outer shape for graph readers.

Generator: immutable code table has sorted reachable functions followed by each owner's loop entries in stable source order. Separate function slots and total code count; loop edges are generated control, outside source recursion checking. One function plus a loop must use a table. No-loop ART1 bytes stay identical. All emission/depth/sequence/slot limits are checked before publication.

One reusable loop body consumes the existing [table [0 frame]]. Initialize index and remaining once. Iteration checks remaining before body; Continue decrements, exits before the final U32 increment, otherwise increments and dynamically invokes the same table entry. Return bypasses continuation and propagates to the ordinary function boundary; only that boundary unwraps flow. Nested loop bodies store once, not one formula per candidate. Runtime reductions/nodes/frames still bound work; no constant-memory claim for evaluator continuations.

Acceptance: empty/reversed/nonzero/literal-leading-zero ranges; 1/4097/5000 iterations and output-size comparison; U32_MAX last index; 2^32+1/P/P+1 rejection; nested same-name scopes, immutable index, repeated local initialization, calls and outer mutation. Explicit return from nested loops bypasses trapping fallbacks; helper return exits only helper; tail discard and empty-body type errors. Differential small loops against seed, large loops against independent values plus adapted raw seed wrapper (flat seed oracle unrolls). Exact depth/slot/table/sequence and runtime quota boundaries, deterministic function reorder/unused definitions, installed Joy JOB→ART execution. Rebuild owners, gates/Trisha baselines/formal honesty, pinned receipts, exact PR integration.

After this slice: Noun/aggregates, constants/attributes, module resolution and complete compiler closure. SH4 whitespace/source-scale boundary remains separate; no C2/fixed-point claim before whole-source gates.
