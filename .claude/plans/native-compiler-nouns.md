## Implementation notes from loop validation
Primitive Noun must remain distinct from INVALID_TYPE; preserve old Field/Bool/U32/Unit IDs. The existing builtin descriptor works for the six Noun signatures because each builtin's parameter types are homogeneous. Exact ASCII identifier matching needs the nox_noun_ prefix and 2/4/8-byte suffix, with length checks; do not rely on the lexer's packed identifier beyond seven bytes. Check ranges before every source read.

A raw entry frame can be constructed from axis1 at leaf0 and quoted zero sibling subtrees while folding its balanced height. Wrap with quoted table and reserved zero using CONS; preserve the old literal subject path for scalar entry. Carry the validated entry ABI explicitly into generation. Scalar main may still use Noun locals/helper returns. Noun main must receive its original subject before any table/frame composition.

Whole-output tests: singleton identity on nonzero nested input; table-dispatched identity helper; head/tail swap; mutable Noun accumulation through loops; local shadowing of the parameter; noun_eq alias identity; user overrides of direct nox_noun_* names and local/callable collisions. Match canonical output bytes/particles, plus seed raw oracle. Invalid projection/atom conversion must compile then trap only when reached, including unused/discarded values. A prepared trace checks computed projection arguments are evaluated once. Existing scalar compiler/ART1 tests keep their original quotas.
